# compute-blake3

`compute-blake3` is to be BLAKE3, written clean room from its specification,
and dedicated to the public domain: pure, safe Rust without dependencies, for
`#![no_std]` without an allocator, of the same shape as `compute-sha256`.
BLAKE3 is one of the checksums that OpenZFS 2.2 and later may stamp on blocks.
It is one of the `compute-*` crates, clean-room, public-domain checksums and
hashes; this release reserves its name, and exports nothing yet.
