# compute-sha512

`compute-sha512` is to be SHA-512 and its truncation SHA-512/256, written clean
room from FIPS 180-4, and dedicated to the public domain: pure, safe Rust
without dependencies, for `#![no_std]` without an allocator, of the same shape
as `compute-sha256`. SHA-512/256 is one of the checksums ZFS may stamp on its
blocks. It is one of the `compute-*` crates, clean-room, public-domain
checksums and hashes; this release reserves its name, and exports nothing yet.
